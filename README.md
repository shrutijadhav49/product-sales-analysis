## 🗄️ SQL Analysis
The SQL file includes queries for:
- Total sales and revenue calculation
- Product-wise and category-wise performance
- Monthly sales trend analysis
- Identification of top-selling products

These queries form the foundation for further analysis and visualization in Power BI.

The Power BI dashboard provides:
